Bellevue Towers Building Skins

Seattle, Washington

This project was to complete a parametric design system that would allow for a dynamic louver system to be applied to the Bellevue Plaza towers. Taking design lead from CDO, each tower would recive a different louver system with a common element to control the depth of each window module. These modules were then rationalized to make fabrication more feasable.
